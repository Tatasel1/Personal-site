Projects

Pac-Man

Development of an educational Pac-Man-type game, which included an evaluation component in the form of a quiz in C#. This component was integrated into the base structure of the game created in Unity. Player movement, interactions, collisions, and menus were developed using C# scripts. The project was realized as a team effort, combining the experience of a simplistic game with an interactive educational component.

Languages used: C# in Unity, C# for the quiz

NextLabTech Enspiro Robot

Development of a robot that automates plant watering, created within the NextLabTech competition. The robot was built using an Arduino UNO board, a humidity sensor, and an automatic system that waters the plant when the soil is dry. The code was written in C++ in the Arduino IDE.

Languages used: C++ for the Arduino script
